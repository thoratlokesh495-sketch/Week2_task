
## Week 2 – Neural Networks and CNN

In Week 2 of my internship, I worked with Neural Networks and Deep Learning using TensorFlow and Keras in Google Colab. I first implemented a basic Feed-Forward Neural Network to understand the fundamentals of neural networks. I then built a CNN image classifier using the CIFAR-10 dataset. I trained and evaluated the CNN using accuracy and loss, and experimented with different hyperparameters such as epochs, batch size, and learning rate. This task helped me understand the basic workflow of image classification and model experimentation.
